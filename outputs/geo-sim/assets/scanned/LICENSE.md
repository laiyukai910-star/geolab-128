# Reference Scan

Rock 09 is an external reference asset from [Poly Haven](https://polyhaven.com/a/rock_09),
distributed under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Poly Haven's [asset license](https://polyhaven.com/license) permits redistribution.
The scan and photographic textures were not authored by the GeoLab project.

GeoLab uses Blender to normalize the pivot and scale, preserve UV/PBR materials,
derive a simplified distant mesh, and package both as local GLB files. Source
download URLs and checksums are recorded in `tools/prepare-rock-scan.ps1`.

This is a visual reference, not a geological classification or a survey of the
simulated region. Instances preserve the scan's aspect ratio, but their displayed
size and placement are illustrative. Source file coordinates are recorded in
`rock-09.json`; they are not independently verified measurements.
