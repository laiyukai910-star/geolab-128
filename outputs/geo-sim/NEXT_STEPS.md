# GeoLab 128 后续接力

## 当前收尾点

- 地图范围保持为 128 km × 128 km，默认网格为 256²。
- 汇流模型已支持 `dinf` / `d8` / `mfd` 三种模式，默认使用 D∞ 连续坡向双接收格分流。
- D∞ 已接入汇流面积、年出流量、河段 `flow_routing`、`flow_divergence`、河道水力诊断、科研验证门控和前端指标条。
- 日尺度/网格气象边界场已接入逐年降水、极端降水、干旱连续日、热/冻日和风暴分位数，并会影响当前年气候和灾害风险。
- 3D 桌面与移动端页面可加载，地形、河网、参数面板和指标条保持可见。
- 当前科研门控仍会把无真实 DEM/土壤/气象/河网/校准输入的运行判定为 demonstration-only，这个限制应保留，避免把程序化地形误标为科研级结果。

## 明天优先推进

1. 将 D∞ 的角度、主/次接收格和分流比例加入格网 CSV 的可选详细导出，便于独立复核。
2. 增加二维浅水方程或栅格扩散波洪水模块，用于替代当前的筛查级洪水风险。
3. 扩展人造设施内部模板库：高层、板楼、联排、小洋房、学校、医院、机场、港口、桥梁、工业园、蓄滞洪区与地下管网。
4. 把 3D 建筑从高度柱体推进到带屋顶、立面、道路连接、地块边界和设施影响半径的分层几何。
5. 继续减少外部采样依赖：增加可编辑气候带、土壤剖面、土地覆盖转移、工程设施参数和校准情景预设。
6. 对真实数据链路做分块导入：DEM、土地覆盖、土壤、气象、河网、站点校准与 OSM 设施分别缓存并生成来源清单。
7. 将 1024²/2048² 高分辨率目标拆成瓦片计算与 Web Worker/WebGPU 渲染，不改变现有 256² 快速交互模式。

## 保留的专业边界

- 当前 D∞ 是连续坡向分流近似，不等同于完整二维水动力。
- 流域圈定仍使用 D8 主接收格反向追踪，以保证边界清晰可审查；D∞ 主要用于汇流量和水力诊断。
- 真实科研使用仍需要真实 DEM、实测河网、气象时序、土壤/土地覆盖和流量站校准共同闭合。
